# Style reference - Battle Zeque Den

Voices per speaker, then the approved pilot (chapter 1, all three heroines). Translators copy the pilot lines
verbatim when their batch contains those ids, and match this voice everywhere else. Plot and who is who:
`docs/synopsis.md`.

## Voices
| Speaker | Japanese markers | English voice | Example |
|---|---|---|---|
| Rufu (17) | あたし, アンタ, ~だぜ, ~かい?, 行くぜェ, river-of-life musings | Breezy, rough-edged tomboy; contractions and casual slang; brave and blunt | "Here goes nothing!" |
| Hamusu (16) | ボク, ~だよォ, ~なァ, ~もん, whiny stretched vowels | Kid-like, bouncy, a little bratty; simple words, exclamations, "you know"; never vulgar | "Aww, it's so hot!" |
| Kairu (18) | です/ます to strangers, ~かしら, ~わね, 私, measured kanji words; stern ~だ when resolved | Composed and articulate, slightly formal; no slang; few contractions when polite, firm short sentences when resolved | "Then I will defeat you!" |
| Seiryu | オレ, いかん, proud | Young warrior, curt and proud | "I live only for the now." |
| Koryu | ~じゃ, ~の, 覚悟せい, old man | Gruff old master: "Hmph", "So...", "Prepare yourself!" | "Seems you have some skill after all." |
| Genbu | ぐへへ, おめえ, ~じゃねえか, crude | Coarse, laughing brute; "ya", dropped g's sparingly ("Heh heh heh... ya beat 'em?"); warm-gruff with Hamusu | "Hamusu, ya little brat!" |
| fire-clan guard | formal, fervent, 朱雀様 | Zealous temple guard, stiff and fatalistic; "Suzaku-sama" | "It is the will of the great god." |
| Suzaku | わたくし, ~ござんせんか, しんぜましょう, お嬢さん | Silky, mocking, old-fashioned lady of the pleasure quarter: "my dear", "why, if it isn't...", "allow me to teach you" | "Why, if it isn't a darling young lady!" |
| Byakko | あたし, アンタ, ~だぜ, fate | Tough, terse young woman; rough like Rufu but colder; "fate" is her word | "Everything with form crumbles someday." |
| Totetsu | 私, おまえ, calm, didactic | Calm, cold, superior philosopher; complete sentences, no contractions | "Everything has a fate decided for it." |

Corrected example (why the pilot reads as it does): AB2E first drafted as "I only live for today. I don't care
about the future!" - accurate but flat; Seiryu's オレは今を生きるのみ is a proud creed, so "I live only for the
now" keeps the swagger.
